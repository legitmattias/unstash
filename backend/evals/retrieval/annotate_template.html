How to use this

Mark what is relevant. 1–9 cycles a result through answers the question → related but not an answer → unmarked. Unmarked means you judged it irrelevant, so a query where you mark nothing is a complete judgement, not a skipped one.

Write why, not where. The note is for the mechanism — "matched a boilerplate footer", "compound split and matched a common word", "right document, snippet from the index page". The stage is computed for you once you name an expected document; you do not need to work it out.

Name the document you expected with e when the right answer is missing. That is what turns "something is wrong" into "it was in the index, fused at 34, and never shown".

Leave it blank when nothing is wrong. One keystroke and move on. Most queries should be this.
