How to use this

Read the results, then write in your own words what first went wrong. Do not try to fit a category — the categories come afterwards, from what you wrote.

If the result set is fine, leave the note blank and move on. Only the first failure goes in: if the right document was never indexed, that is the note, not the fact that ranking and snippet are also wrong.

Marking relevant results is optional but nearly free while you are reading, and each mark becomes a golden-set entry.
